ADO Gantt — Setup Wizard

Deploy your multi-project Gantt dashboard to Azure. You'll host it in your own Azure subscription, signed in with Entra ID. After the initial provision (~10 min), you add ADO projects through the deployed app itself — no more running this wizard.

1
Prerequisites
Check that Node.js and the Azure CLI are installed.
2
Azure login
Sign in and pick the subscription that will own the dashboard resources.
3
Resource group & region
Pick an existing resource group or enter a name to create a new one.
4
Site name & sign-in policy
The site name becomes your Azure subdomain (`.azurestaticapps.net`) and also names the storage + Key Vault. Sign-in policy lets you restrict who can sign in with Entra.
5
Entra ID app registration
Static Web Apps needs an Entra app registration to authenticate users. Follow the two commands below in your terminal, then paste the client id and secret here.
1. Create the app registration: 
az ad app create --display-name "<siteName> Auth" --sign-in-audience AzureADMyOrg --web-redirect-uris "https://<siteName>.azurestaticapps.net/.auth/login/aad/callback"
Copy the appId from the output — that's your client id.

2. Create a client secret (replace <appId> with the value from step 1): 
az ad app credential reset --id <appId> --years 2
Copy the password value — that's your client secret. You won't see it again.
6
Provision & deploy
Creates the Static Web App, Key Vault, Storage Account, and role assignments, then deploys the app.
