Projects

Each project below appears in the header dropdown of the main dashboard. All authenticated users can view every project. Only admins can add, edit, or remove projects.

Access

To invite another user or promote them to admin, use the Static Web Apps role invitations in the Azure Portal (Overview → Role management → Invite). Anyone in your Entra tenant can sign in and view projects; only accounts with the admin role can manage them.

Current admins are tracked by Azure Static Web Apps, not by this app.

Add project

Enter the ADO org, project name, and a Personal Access Token with Work Items: Read, write, & manage scope. The PAT is validated with a smoke call before it's stored in Key Vault.

1. Go to https://dev.azure.com/<YOUR-ORG>/_usersSettings/tokens
2. Click "+ New Token" → give it a name → select "Custom defined"
3. Check Work Items → Read, write, & manage
4. Copy the token and paste it here.

Remove project?

This deletes the project row from Table Storage and soft-deletes its PAT and admin secret from Key Vault. The ADO project itself is not touched.
